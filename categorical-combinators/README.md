# Categorical combinators

We show here the equivalence between CCaTT and categorical combinators for cartesian closed categories, including the required fact that pasting schemes are uniquely inhabited.

## Tool disclosure

Some of the code results from heavy interaction between Claude Code (Opus 4.7 and 5) and myself. This is mostly true for normalization by evaluation (in [CCNF](CCNF.agda)) and the fact that pasting schemes are uniquely inhabited (in [CCPS](CCPS.agda)).

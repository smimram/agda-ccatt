# Unbiased bicategories

We show that there is an equivalence between

- 2-dimensional models of CaTT,
- bicategories.

This version contains explicit substitutions and is close to traditional formalization. We also tried [a variant where pasting schemes already contain a substitution](nosub), which was nicer from a type-theoretic point of view, but do not know how to express the coherence condition there.

This is work in progress.
